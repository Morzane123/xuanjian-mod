# 玄剑公会联动模组 指令说明书

> 所有指令以 `/xj` 开头，客户端模组模式下在游戏内输入即自动补全，无需服务器安装模组。

## 绑定（必做）

| 指令 | 说明 |
|:---|:---|
| `/xj bind <官网账号>` | 将当前游戏角色与官网账号绑定。官网账号可为用户名或昵称。执行后官网向该账号邮箱发送确认邮件，点击邮件内确认链接即完成绑定。若账号未绑定邮箱，会提示先在官网个人设置中绑定邮箱。绑定成功后，玩家在官网个人档案中的「游戏 ID」自动填写当前游戏内名字。 |
| `/xj bind status` | 查看绑定状态（实时从官网同步，邮箱确认后无需重启游戏即可识别已绑定） |

## 签到

| 指令 | 说明 |
|:---|:---|
| （自动） | 玩家加入任意服务器后自动完成官网每日签到（仅限已绑定玩家，每天一次） |
| `/xj checkin` | 手动签到（与自动签到等效） |

## 任务

| 指令 | 说明 |
|:---|:---|
| `/xj task list` | 查看当前可接取的官方任务列表 |
| `/xj task accept <任务ID>` | 接取指定任务 |
| `/xj task verify <任务ID> <验证码>` | 提交完成验证码，完成任务并获得贡献点 |
| `/xj task my` | 查看我已接取的任务与状态 |

## 贡献点

| 指令 | 说明 |
|:---|:---|
| `/xj cb` | 查看我的贡献点余额 |
| `/xj cb pay <玩家ID> <金额>` | 向指定玩家发起贡献点转账，随后输入 `/xj cb confirm` 二次确认执行（120 秒内有效） |
| `/xj cb confirm` | 确认执行待确认的转账 |
| `/xj cb cancel` | 取消待确认的转账 |

## 申报

| 指令 | 说明 |
|:---|:---|
| `/xj claim <数量> <理由>` | 提交贡献点申报（理由至少 10 个字符），等待管理员审核发放 |

## 在线玩家

| 指令 | 说明 |
|:---|:---|
| `/xj online` | 查看当前在线的玄剑玩家（含所在服务器，仅统计已绑定官网账号的玩家，60 分钟 TTL 过期过滤） |

## 图形界面

| 指令 | 说明 |
|:---|:---|
| `/xj gui` | 打开信息面板：绑定状态、贡献点余额、在线玄剑玩家（支持刷新） |
| `/xj settings` | 打开设置页：官网地址、本服地址、同步 / 心跳间隔（Cloth Config，保存即生效） |

## 其他

| 指令 | 说明 |
|:---|:---|
| `/xj help` | 查看全部可用指令 |
| `/xj version` | 查看模组版本 |

## 自动行为

- **自动签到**：加入任意服务器后自动完成官网每日签到（已绑定玩家）
- **上下线上报**：加入 / 退出服务器自动向官网上报在线状态（仅已绑定玩家），崩溃 / 断网由心跳续报兜底
- **活跃心跳**：已绑定玩家在线期间自动周期上报，参与官网活跃统计
- **日报 / 决策同步**：官网发布新日报或决策公示时，已绑定玩家游戏内即时收到提示
- **申报审核提醒**：新的贡献点申报待审核时，在线的官网管理员游戏内即时收到提醒

## 管理员配置

在线统计依赖官网管理后台的「服务器白名单」：

1. 在官网管理后台「模组管理」中添加服务器名称与公网地址（`mod_servers.server_ip`，模组上报时按去端口地址匹配）。
2. 玩家客户端加入任意白名单内服务器后自动上报上线，无需任何服务器密钥。
3. 模组配置中的 `server.key` 已弃用，可留空。
