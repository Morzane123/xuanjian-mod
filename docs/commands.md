# 玄剑公会联动模组 指令说明书

> 所有指令以 `/xj` 开头，游戏内与服务器控制台均可执行。

## 绑定（必做）

| 指令 | 说明 |
|:---|:---|
| `/xj bind <官网账号>` | 将当前游戏角色与官网账号绑定。官网账号可为用户名或昵称。执行后官网将向该账号邮箱发送确认邮件，点击邮件内确认链接即完成绑定。若账号未绑定邮箱，会提示先在官网个人设置中绑定邮箱。绑定成功后，玩家在官网个人档案中的「游戏ID」自动填写当前游戏内名字。 |
| `/xj bind info` | 查看当前绑定状态 |

## 签到

| 指令 | 说明 |
|:---|:---|
| （自动） | 玩家登录服务器后自动完成官网每日签到（仅限已绑定玩家，每天一次） |
| `/xj checkin` | 手动签到（与自动签到等效） |

## 任务

| 指令 | 说明 |
|:---|:---|
| `/xj task list` | 查看当前可接取的官方任务与玩家任务列表 |
| `/xj task accept <任务ID>` | 接取指定任务 |
| `/xj task verify <任务ID> <验证码>` | 提交完成验证码，完成任务并获得贡献点 |
| `/xj task my` | 查看我已接取的任务与状态 |

## 贡献点

| 指令 | 说明 |
|:---|:---|
| `/xj cb` | 查看我的贡献点余额 |
| `/xj cb pay <玩家ID> <金额>` | 向指定玩家转账贡献点。执行后需再次输入 `/xj cb confirm` 二次确认，转账前还会向对方确认 |

## 申报

| 指令 | 说明 |
|:---|:---|
| `/xj claim <数量> <理由>` | 提交贡献点申报（理由至少 10 个字符），等待管理员审核 |

## 在线玩家

| 指令 | 说明 |
|:---|:---|
| `/xj online` | 查看当前在线玩家列表（含服务器名与人数） |

## 其他

| 指令 | 说明 |
|:---|:---|
| `/xj help` | 查看全部可用指令 |
| `/xj version` | 查看模组版本 |

## 服务器管理员配置

管理员还需在官网管理后台配置：

1. **服务器 IP**：管理后台「模组管理」中添加服务器名称与公网 IP，模组上报在线玩家时按 IP 归类。
2. **服务器密钥**：管理后台生成服务器密钥，填入 `config/xuanjianmod.properties` 的 `server.key`。密钥用于在线玩家上报与「新申报审核提醒」接口鉴权。
